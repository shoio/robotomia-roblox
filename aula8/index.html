Loja: gaste as moedas

Três moedas compram velocidade. Se você não tiver as três, não leva — e é o código que decide. São 19 passos, 50 minutos. Faça um de cada vez e só passe adiante depois de conferir o quadro verde.

Antes de digitarSe este computador ainda não foi preparado, faça o passo 2 da Aula 2 primeiro: desligar o assistente de código e o fechamento automático. Sem isso o editor escreve linhas que você não pediu.
Projeto novoComeça do zero. A primeira metade refaz o placar e a moeda da Aula 5 — vai rápido, você já sabe.
O conceito de hojeif … then … else … end: o código olha para um número e escolhe o que fazer.

13

Escreva a loja

Treze linhas. Repare que existe um if dentro do outro:

⌨ digite você mesmo — não copie
  1. local loja = script.Parent
  2. local preco = 3
  4. loja.Touched:Connect(function(parte)
  5. local jogador = game.Players:GetPlayerFromCharacter(parte.Parent)
  6. if jogador then
  7. local moedas = jogador.leaderstats.Moedas
  8. if moedas.Value >= preco then
  9. moedas.Value = moedas.Value - preco
  10. parte.Parent.Humanoid.WalkSpeed = 50
  11. end
  12. end
  13. end)
as linhas em cinza o editor escreve sozinho — não digite elas

O primeiro if pergunta “é um jogador?”. O segundo pergunta “ele tem dinheiro?”. São três end no fim, e o último com ).

Não digite as linhas em cinza. O editor escreve os end sozinho quando você aperta Enter. E não aperte Tab — ele já empurra as linhas para dentro.

Está certo seNenhum risco vermelho, e o editor desenhou as linhas verticais dos dois if.
Não deu certo?
Sobraram end a mais
Você digitou os que o editor já tinha escrito. Apague os extras até o código ficar igual ao da aula.
Risco vermelho no fim
Conte os end: são três, e o último é end).
A indentação saiu diferente
O editor recua sozinho. Não use Tab — ele serve para outra coisa. Se ficou torto, apague a linha e escreva de novo.
O que é >= ?
É “maior ou igual”. Dois símbolos, sem espaço entre eles.
14

Entenda a decisão

local preco = 3 — guarda o número 3 com o nome preco. Assim, se você quiser mudar o preço, muda num lugar só.

if moedas.Value >= preco then — “se o que ele tem for maior ou igual ao preço…”. É aqui que o código decide.

moedas.Value = moedas.Value - preco — cobra: tira 3 do que ele tinha.

Humanoid.WalkSpeed = 50 — entrega o produto. A velocidade normal é 16; 50 é correr muito.

E se não tiver as três moedas? Nada acontece. O código simplesmente pula tudo que está dentro do if.

Está certo seVocê consegue dizer o que acontece ao pisar na loja com 2 moedas.
Não deu certo?
Por que usar preco em vez de 3 direto?
Porque aparece duas vezes. Com um nome só, você muda o preço num lugar e vale nos dois.
