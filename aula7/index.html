O martelo que gira

Uma barra que roda sem parar e derruba quem estiver na frente. Hoje o código aprende a repetir. São 19 passos, 50 minutos. Faça um de cada vez e só passe adiante depois de conferir o quadro verde.

Antes de digitarSe este computador ainda não foi preparado, faça o passo 2 da Aula 2 primeiro: desligar o assistente de código e o fechamento automático. Sem isso o editor escreve linhas que você não pediu.
Projeto novoComeça do zero, com uma peça só.
Cuidado com o laçowhile true do repete para sempre. Sem o task.wait lá dentro, o Studio trava. Essa linha não é opcional.

10

Escreva o laço

Seis linhas. As duas do meio entram para dentro — o editor faz isso sozinho.

⌨ digite você mesmo — não copie
  1. local martelo = script.Parent
  3. while true do
  4. martelo.CFrame = martelo.CFrame * CFrame.Angles(0, 0.05, 0)
  5. task.wait(0.03)
  6. end
as linhas em cinza o editor escreve sozinho — não digite elas

Repare que este código não tem Touched. Ele não espera nada acontecer — ele age sozinho, o tempo todo.

Não digite as linhas em cinza. O editor escreve os end sozinho quando você aperta Enter. E não aperte Tab — ele já empurra as linhas para dentro.

Está certo seNenhum risco vermelho, e o editor desenhou a linha vertical ligando o while ao end.
Não deu certo?
Sobraram end a mais
Você digitou os que o editor já tinha escrito. Apague os extras até o código ficar igual ao da aula.
Risco vermelho no fim
Falta o end. Este laço termina com end sozinho, sem parêntese — diferente dos anteriores.
Escrevi CFrame errado
São dois maiúsculos: C e F. CFrame.Angles também.
O editor completa sozinho
Aperte Esc para dispensar a sugestão.
11

Entenda o laço

while true do … end — “enquanto for verdade, faça isto”. E true é sempre verdade. Então: faça isto para sempre.

Tudo que estiver entre o do e o end se repete sem parar.

martelo.CFrame = martelo.CFrame * CFrame.Angles(0, 0.05, 0) — “pegue onde a peça está e gire um tiquinho”. O 0.05 é o tamanho do tiquinho.

task.wait(0.03) — espere trinta milésimos de segundo antes de repetir.

Está certo seVocê sabe dizer qual linha faz o martelo girar mais rápido.
Não deu certo?
Qual muda a velocidade?
Duas: aumentar o 0.05 gira mais por vez; diminuir o 0.03 repete mais vezes por segundo.
12

Por que o task.wait é obrigatório

Um laço while true sem espera roda milhões de vezes por segundo. O computador não dá conta e o Studio congela.

O task.wait é o que dá um respiro. É a linha mais importante do código de hoje, e é a que todo mundo esquece.

Não teste sem ela. Se travar, feche o Studio pelo gerenciador de tarefas e perca tudo o que não salvou.

Está certo seVocê tem o task.wait(0.03) dentro do laço, antes do end.
Não deu certo?
Já travou aqui
Feche o Studio à força e abra de novo. Da próxima vez, salve antes de testar um laço.

17

Faça o martelo subir e descer

Troque o meio do laço por estas duas linhas, uma embaixo da outra:

martelo.CFrame = martelo.CFrame * CFrame.Angles(0.05, 0, 0)

O primeiro número gira num eixo diferente. Experimente mudar qual dos três números não é zero e veja o que acontece com cada um.

Está certo seVocê descobriu, testando, o que cada um dos três números faz.
Não deu certo?
Todos parecem iguais
Teste um de cada vez, com os outros dois em zero. A diferença fica clara.
A peça sumiu
Ela girou para um lugar estranho. Pare o jogo — ela volta ao normal.

A cópia já vem com o script dentro e gira sozinha. Agora são dois obstáculos em fila.

Está certo seDois martelos girando, um depois do outro.
Não deu certo?
Os dois giram igualzinho
Mude o número de um deles para eles ficarem fora de sincronia. Fica bem mais difícil.
A cópia não gira
Você duplicou antes de pôr o script. Apague e duplique o que tem o Script dentro.
