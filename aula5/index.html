Um número na tela que sobe quando você encosta na moeda — e a moeda some. São 19 passos, 50 minutos. Faça um de cada vez e só passe adiante depois de conferir o quadro verde.

Projeto novoComeça do zero. Hoje são dois scripts, em lugares diferentes.
A palavra mais importanteleaderstats, tudo junto e tudo minúsculo. É esse nome exato que faz o placar aparecer. Com uma letra diferente, nada acontece.

6

Escreva o placar

Este é o código que cria o placar. Nove linhas:

⌨ digite você mesmo — não copie
  1. game.Players.PlayerAdded:Connect(function(jogador)
  2. local pasta = Instance.new("Folder")
  3. pasta.Name = "leaderstats"
  4. pasta.Parent = jogador
  6. local moedas = Instance.new("IntValue")
  7. moedas.Name = "Moedas"
  8. moedas.Value = 0
  9. moedas.Parent = pasta
  10. end)

Cuidado com três coisas: leaderstats é tudo minúsculo e entre aspas; IntValue tem I e V maiúsculos; e o Moedas entre aspas é o nome que vai aparecer na tela.

Está certo seNenhum risco vermelho.
Não deu certo?
Risco vermelho no fim
Falta o end) da última linha — com o parêntese.
Escrevi Leaderstats com L maiúsculo
Não funciona. Tem que ser leaderstats, tudo minúsculo. É a Roblox que exige esse nome exato.
O editor completa sozinho
Aperte Esc para dispensar a sugestão.
7

Entenda o placar

game.Players.PlayerAdded — “quando um jogador entrar no jogo”.

Instance.new("Folder") — cria uma pasta nova, do nada. Instance.new é como o código fabrica coisas.

pasta.Name = "leaderstats" — a pasta ganha esse nome. É esse nome que a Roblox procura para desenhar o placar na tela. Qualquer outro nome e não aparece nada.

Instance.new("IntValue") — cria um número. Int é número inteiro: 0, 1, 2. Sem vírgula.

moedas.Parent = pasta — põe o número dentro da pasta. É a pasta dentro do jogador, e o número dentro da pasta.

Está certo seVocê consegue explicar por que a pasta tem que se chamar leaderstats.
Não deu certo?
O que é Parent de novo?
É “quem está segurando”. Aqui você está dizendo onde cada coisa nova vai morar.

Escreva o código da moeda

Apague a linha pronta e escreva:

⌨ digite você mesmo — não copie
  1. local moeda = script.Parent
  3. moeda.Touched:Connect(function(parte)
  4. local jogador = game.Players:GetPlayerFromCharacter(parte.Parent)
  5. if jogador then
  6. jogador.leaderstats.Moedas.Value = jogador.leaderstats.Moedas.Value + 1
  7. moeda:Destroy()
  8. end
  9. end)

GetPlayerFromCharacter é uma palavra só, com quatro maiúsculas. Copie com calma.

Está certo seNenhum risco vermelho, e são dois end, o último com ).
Não deu certo?
Risco vermelho em GetPlayerFromCharacter
Confira as maiúsculas: G, P, F, C.
Risco no fim
Falta um end ou o parêntese final.
16

Entenda a moeda

GetPlayerFromCharacter(parte.Parent) — “descubra qual jogador é esse boneco”. Na aula da lava a gente só perguntava se era um boneco; agora precisamos saber de quem é, para somar no placar certo.

jogador.leaderstats.Moedas.Value + 1 — pega o número que está lá e põe um a mais. Repare no caminho: jogador → pasta → número → valor.

moeda:Destroy() — a moeda se apaga. Por isso você não pega a mesma moeda duas vezes.

Está certo seVocê sabe dizer o que aconteceria sem a linha do Destroy.
Não deu certo?
O que aconteceria sem o Destroy?
A moeda ficaria lá e o número subiria sem parar enquanto você encostasse.
