Botão e porta

Você pisa num lugar e outra coisa, longe dali, acontece. É o primeiro script que mexe numa peça que não é a dele. São 20 passos, 50 minutos. Faça um de cada vez e só passe adiante depois de conferir o quadro verde.

Antes de digitarO passo 2 desta aula prepara o editor: desligar o assistente de código e o fechamento automático. Não pule — sem isso o editor escreve linhas que você não pediu.
Projeto novoComeça do zero. Você vai fazer duas peças: uma porta e um botão.
O nome importaA porta precisa se chamar exatamente Porta. O script procura por esse nome — errou a letra, não acha.

  2. local porta = workspace.Porta
  4. botao.Touched:Connect(function(parte)
  5. local humano = parte.Parent:FindFirstChild("Humanoid")
  6. if humano then
  7. porta.Transparency = 1

15

Entenda a linha nova

local porta = workspace.Porta

workspace é o mundo inteiro — tudo que existe no seu jogo. O ponto quer dizer “de dentro dele”. Então a linha lê assim: “procure no mundo a peça chamada Porta e chame ela de porta”.

Antes você só usava script.Parent, que é “a peça onde eu moro”. Agora você consegue pegar qualquer peça, esteja onde estiver.

É por isso que o nome tem que bater exatamente. O Roblox procura pelo nome, não adivinha.

Está certo seVocê consegue explicar a diferença entre script.Parent e workspace.Porta.
Não deu certo?
E se eu tiver duas peças chamadas Porta?
Ele pega uma só, e você não escolhe qual. Nomes repetidos dão confusão — use Porta1, Porta2.

18

Faça o contrário

Troque só os quatro valores das linhas de dentro do if. Elas ficam assim, nesta ordem:

porta.Transparency = 0
porta.CanCollide = true
task.wait(3)
porta.Transparency = 1
porta.CanCollide = false

Ou seja: onde estava 1 ponha 0, onde estava 0 ponha 1, e troque cada false por true e cada true por false.

Antes de jogar, a porta precisa começar invisível: clique nela na lista e, na busca das Propriedades, ponha Transparency = 1 e desmarque CanCollide.

Agora a porta aparece quando você pisa, em vez de sumir. Vira armadilha.

Está certo seA porta começa invisível e aparece quando você pisa no botão.
Não deu certo?
Me perdi nos números
0 é sólida e visível, 1 é invisível. true é “dá para esbarrar”, false é “atravessa”.
