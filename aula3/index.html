Aula 3 · o código conta o tempo

Plataformas que somem

Você pisa, o chão desaparece por dois segundos e volta. É o obby virando um jogo de tempo. São 19 passos, 50 minutos. Faça um de cada vez e só passe adiante depois de conferir o quadro verde.

Projeto novoEsta aula começa do zero, num projeto novo. Você não precisa do arquivo da aula passada.
Já sabe distoCriar, ancorar, pintar, renomear e colocar o Script é igual à Aula 2. Se esqueceu algum, volte lá e confira.
AtalhosEste material usa Ctrl, do Windows. Num Mac, troque Ctrl por ⌘.

11

Escreva a primeira linha

Como na aula passada, a primeira linha dá um apelido para a peça:

⌨ digite você mesmo — não copie
  1. local piso = script.Parent

Agora, escrever piso é a mesma coisa que escrever “a placa azul”.

Está certo seSem risco vermelho embaixo.
Não deu certo?
Risco vermelho
Confira o ponto entre script e Parent, e o P maiúsculo.
12

Escreva o resto

O código inteiro fica assim. Use Tab no começo das linhas que entram para dentro:

⌨ digite você mesmo — não copie
  1. local piso = script.Parent
  3. piso.Touched:Connect(function(parte)
  4. local humano = parte.Parent:FindFirstChild("Humanoid")
  5. if humano then
  6. piso.Transparency = 0.7
  7. piso.CanCollide = false
  8. task.wait(2)
  9. piso.Transparency = 0
  10. piso.CanCollide = true
  11. end
  12. end)

São dois end e o último termina com ). É onde todo mundo erra.

Está certo seNenhum risco vermelho, e aparecem as linhas verticais ligando o function ao end.
Não deu certo?
Risco vermelho no fim
Falta um end ou o ) final.
task.wait dá erro
É task.wait(2), com ponto entre task e wait.
Escrevi Transparency errado
Tem que ser exatamente assim, com T maiúsculo e y no fim.
13

Entenda o que você escreveu

piso.Transparency = 0.7 — deixa a peça quase invisível. 0 é sólida, 1 é totalmente transparente.

piso.CanCollide = false — esta é a linha que faz você cair. CanCollide é “dá para esbarrar?”. Com false, o boneco atravessa.

task.wait(2) — espere dois segundos. O código para aqui e continua depois.

As duas últimas linhas desfazem tudo: a peça volta a ser sólida e visível.

Sem o CanCollide a peça só ficaria transparente e você continuaria andando por cima dela, como se fosse um vidro.

Está certo seVocê sabe dizer qual linha faz o boneco cair — e não é a da transparência.
Não deu certo?
Qual a diferença entre as duas?
Transparency é só aparência. CanCollide é se a peça existe para o corpo bater.

Jogue e pise

Aperte o ▶ azul.

Você nasce em cima da placa. No instante em que encosta, ela fica quase invisível, você atravessa e cai no chão cinza. Dois segundos depois ela volta.

Está certo seA placa azul ficou translúcida e você caiu. Depois ela voltou sólida.
Não deu certo?
Nada aconteceu
Três conferências, nesta ordem: 1) o Script está dentro do Piso? 2) sobrou risco vermelho no código? 3) você salvou o código antes de jogar? Basta clicar fora do editor.
Ficou transparente mas não caí
Faltou a linha piso.CanCollide = false.
Caí para sempre
A peça sumiu e não voltou: confira as duas últimas linhas, que desfazem a mudança.

17

Faça um caminho de plataformas

Agora o divertido. Com o jogo parado:

1. Botão direito no Piso da lista → Duplicar.
2. A cópia nasce no mesmo lugar. Use a ferramenta Mover e arraste a cópia pela seta para o lado.
3. Repita mais duas ou três vezes, formando um caminho.

Cada cópia já vem com o script dentro. Todas somem sozinhas.

Está certo seVocê tem três ou quatro placas azuis em fila, e na lista aparecem vários Piso.
Não deu certo?
A cópia veio sem script
Você duplicou a peça errada. Apague e duplique o Piso que tem o Script dentro.
Arrastei e a peça foi para longe
Ctrl + Z e arraste devagar, pela seta, não pelo meio da peça.
As placas ficaram grudadas
Diminua o tamanho delas: filtro size, valor 8, 1, 8.
18

Atravesse o caminho

Jogue de novo e tente atravessar sem cair.

Não dá para parar: cada placa aguenta você por um instante só. Esse é o jogo.

Está certo seVocê conseguiu chegar do outro lado pelo menos uma vez.
Não deu certo?
É impossível
Aumente o tempo: troque task.wait(2) por task.wait(4) em uma das placas e veja a diferença.
É fácil demais
Diminua para task.wait(1) e afaste mais as placas.
